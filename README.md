# 혈압·혈당 수첩

혈압, 혈당, 운동 여부, 혈압약·영양제 복용을 날짜별로 기록하고 월간 달력과 기간별 추이 그래프로 확인하는 웹페이지입니다.

- 파일 하나(`index.html`)로 동작합니다. 빌드가 필요 없습니다.
- 기간(7일·3개월·1년·전체·직접 지정)을 골라 혈압·혈당 추이와 평균을 볼 수 있습니다.
- '내 정보'에 이름, 높음 기준값, 복용약 이름을 저장합니다.
- 기록과 내 정보는 사용하는 기기의 브라우저(localStorage)에 저장됩니다. 다른 기기로 옮기려면 '내보내기/가져오기'를 사용하세요.
- 색 구분은 일반적인 참고 기준이며 진단이 아닙니다.
